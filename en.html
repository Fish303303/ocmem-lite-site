Why yet another memory plugin

Most memory plugins dump retrieved context on every turn, or ship a few hundred megabytes of embeddings. OCMem bets the other way.

01AI extraction, rules as fallback

A small model reads each message and pulls out durable preferences; if the call fails, local regex takes over. Never blocks a conversation.

02Small, fixed digest

Up to six facts of the current topic are written into a managed block, so they ride along with the system prompt — no extra tool call, no vector search.

03Topic groups

Only the current topic (coding / computer / work / life) is expanded; the rest show up as counts in a single line.

04Search on demand

One memory tool for search / list / forget. Everything else stays out of the prompt.

Measured: +90 tokens per run

Method: two fresh sessions with the identical prompt, one with OCMem installed and one without; prompt tokens read from OpenCode's session database.

The digest block was 169 characters at the time. Add the always-registered memory tool schema (~100 tokens) and the total overhead is about 200 tokens. In long sessions the prefix is cached, so the billed cost is lower.

Three steps

Requires Node.js 18+ and OpenCode. Everything is stored in a local JSON file.

  1. Install the plugin
    Run opencode plugin add opencode-ocmem in your terminal.
  2. Just chat
    Durable preferences are captured automatically; near-duplicates are merged. No manual curation.
  3. Search when needed
    Ask for memory search <keyword>, or simply "what did I tell you before".

What it actually does

Auto-capture

Only declarative sentences that look like durable preferences survive; questions, one-off commands and test chatter are filtered out.

Dedupe

Character-bigram Jaccard ≥ 0.75 counts as a near-duplicate and is merged into one entry.

Managed block

The digest lives between <!-- ocmem:begin --> and <!-- ocmem:end -->, so you can clean it up by hand any time.

Short-term recall

The last few non-question messages from previous sessions are kept, so a fresh session can pick up where you left off.
